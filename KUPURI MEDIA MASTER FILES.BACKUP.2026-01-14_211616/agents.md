## 🏃 THE RELAY — Sequential Agent Orchestration Framework

### CORE PRINCIPLE
Agents execute **sequentially, not in parallel**. Each agent completes its task, hands off the baton to the next agent **only after a validation gate confirms quality and BMAD compliance**.

```
Runner A completes leg 1 → passes baton to Validator
Validator checks (no drops, quality intact)
If valid → Runner B takes off with full context
Continue until finish line

ANY GATE FAILS → HALT + Report blockers
```

### RELAY GATES (VALIDATION CHECKPOINTS)

#### Gate 1: Authorization Syntax Check
- **Executor:** Validation Agent
- **Checks:** Syntax valid, scope unambiguous, no conflicts
- **Output:** "BATON READY FOR AGENT A" or "CORRECTION NEEDED"

#### Gate 2: Scope Execution Validation
- **Executor:** Risk & Impact Analyst Agent
- **Checks:** Only authorized tasks executed, no scope creep, P5 guarantees intact
- **Output:** "BATON READY FOR AGENT B" or "BLOCKER DETECTED"

#### Gate 3: Documentation & Alignment Check
- **Executor:** Validation Agent
- **Checks:** Changes align with docs, no contradictions, audit trail clear
- **Output:** "BATON READY FOR AGENT C" or "ALIGNMENT ISSUES"

#### Gate 4: Infrastructure Readiness Check
- **Executor:** Validation Agent
- **Checks:** Dependencies available, no external blockers
- **Output:** "BATON READY FOR FINAL VALIDATION" or "INFRASTRUCTURE BLOCKERS"

#### Gate 5: Final BMAD Compliance Check
- **Executor:** Final Validation Agent
- **Checks:** Phase boundaries preserved, all work reversible, sign-off ready
- **Output:** "RELAY COMPLETE — PHASE READY" or "ISSUES FOUND"
